# 📘 Methodology

## Overview
The methodology used in this project focuses on analyzing student academic performance using Exploratory Data Analysis (EDA), statistical analysis, and data visualization techniques.

The complete workflow includes:
- Data Collection
- Data Cleaning
- Data Preprocessing
- Exploratory Data Analysis
- Visualization
- Insight Generation
- Dashboard Development

---

# 1️⃣ Data Collection

The dataset used in this project was collected from Kaggle and contains student academic and demographic information.

### Dataset Includes
- Student ID
- GPA
- Attendance
- Study Hours
- Grade Class
- Age
- Gender
- Ethnicity
- Parental Support
- Tutoring
- Extracurricular Activities

---

# 2️⃣ Data Cleaning & Preprocessing

The dataset was cleaned and prepared using Python libraries such as Pandas and NumPy.

### Tasks Performed
- Removed duplicate values
- Checked missing values
- Converted categorical data
- Data formatting and transformation
- Feature selection

---

# 3️⃣ Exploratory Data Analysis (EDA)

EDA was performed to identify patterns, relationships, and trends in student performance.

### Visualization Techniques Used
- Histogram
- Boxplot
- Scatterplot
- Heatmap
- Countplot
- Pie Chart
- Bar Chart
- Line Plot

### Libraries Used
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

# 4️⃣ Statistical Analysis

Different statistical methods were applied to understand:
- GPA distribution
- Attendance impact
- Study hour trends
- Parental support effects
- Gender-based performance analysis

---

# 5️⃣ Dashboard Development

An interactive dashboard was developed using Power BI for visual representation of insights.

### Dashboard Features
- Average GPA
- Average Study Time
- Average Absences
- Student Count
- Gender Distribution
- Performance Filters

---

# 6️⃣ Insight Generation

The final step involved extracting meaningful insights from visualizations and statistical analysis.

### Key Findings
- Students with higher study hours generally achieve better GPA.
- Attendance strongly impacts academic performance.
- Parental support improves student outcomes.
- Extracurricular activities positively influence performance.

---

# Conclusion

The methodology successfully demonstrates how data analytics and visualization techniques can be applied in the education sector to understand student behavior and improve academic decision-making.

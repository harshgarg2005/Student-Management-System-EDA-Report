# 📘 Student Management System EDA Report

## Project Overview
This project focuses on analyzing student academic performance using data analytics and visualization techniques.

The project uses:
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI

to generate insights regarding:
- GPA
- Attendance
- Study Hours
- Parental Support
- Tutoring
- Extracurricular Activities

---

# Objectives
- Analyze student performance
- Identify academic trends
- Visualize educational data
- Generate meaningful insights
- Support data-driven decision-making

---

# Key Features
- Exploratory Data Analysis
- Statistical Analysis
- Interactive Dashboard
- System Diagrams
- Educational Insights

---

# Results
The project successfully identified:
- Positive impact of study hours on GPA
- Importance of attendance
- Effect of parental support
- Balanced gender-based academic performance

---

# Conclusion
The Student Management System EDA Report demonstrates the practical implementation of data analytics in the education sector and provides meaningful academic insights through visualization and statistical analysis.
